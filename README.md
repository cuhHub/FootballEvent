# cuhHub - Football Event

## 📚 Overview
An addon managing the cuhHub Football Event.

This addon uses [Noir](https://github.com/cuhHub/Noir).

## ⚙️ Setup
⚠️ [cuhkit](https://github.com/cuhHub/cuhkit) is required.

1) Run `git clone https://github.com/cuhHub/FootballEvent`.
2) Run `cuhkit setup`.
3) Run `build.bat`. Do this for every change to the code. For full stacktraces with [SSSWTool](https://github.com/Avril112113/SSSWTool), use `build.bat yes`.
4) Edit `src/config.lua` if needed.
5) Run the addon in a save and all should work.
